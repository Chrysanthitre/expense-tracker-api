# Expense Tracker API

A REST API for personal finance management — tracking expenses 
by category with monthly analytics and reporting.

> Currently in development

## Tech Stack
- Java, Spring Boot
- PostgreSQL
- Docker
- REST API

## Planned Features
- Add / edit / delete expenses
- Category management (food, transport, shopping etc.)
- Monthly statistics and analytics
- Containerized with Docker for easy deployment

## Status
Active development — started May 2026
